# Planner

Planner es el módulo de planificación avanzada de producción (APS) de Oxygen Suite. Permite programar órdenes de manufactura, gestionar la capacidad de recursos y visualizar el plan en un Gantt interactivo.

## Módulos principales

  </Card>
  <Card title="Programación" icon="calendar-days" href="/planner/scheduling">
