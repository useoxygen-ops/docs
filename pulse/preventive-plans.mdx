## ¿Qué es un Plan Preventivo?

Un plan preventivo es una regla que genera órdenes de mantenimiento automáticamente, sin intervención manual. Definís cuándo y cómo se debe hacer el trabajo, y Pulse se encarga de crear las órdenes en el momento correcto.

Esto elimina el riesgo de olvidar un mantenimiento programado y garantiza que los equipos reciban atención antes de que fallen.

## Tipos de disparadores

El disparador define **cuándo** se genera una nueva orden.

### Por calendario

Genera órdenes según una frecuencia fija en el tiempo.

**Ejemplos:**
- Cambio de aceite cada 30 días
- Revisión de filtros cada 3 meses
- Lubricación semanal todos los lunes

Configurás la frecuencia (cada X días, semanas o meses) y con cuántos días de anticipación se debe crear la orden para que haya tiempo de planificarla.

### Por uso

Genera una orden cuando un parámetro del activo alcanza un valor acumulado.

**Ejemplos:**
- Mantenimiento cada 500 horas de operación
- Cambio de rodamiento cada 10,000 ciclos
- Revisión cada 50,000 unidades producidas

Requiere que el activo tenga un [parámetro](/pulse/assets#parámetros-del-activo) con lecturas registradas. El plan monitorea el valor acumulado y genera la orden cuando se alcanza el umbral.

### Por condición

Genera una orden cuando un parámetro del activo sale de un rango aceptable.

**Ejemplos:**
- Temperatura de rodamiento supera 80°C
- Presión de aceite cae por debajo de 2 bar
- Vibración supera el límite máximo

Configurás los valores mínimo y máximo aceptables. Si el parámetro cruza esos límites, se genera automáticamente una orden correctiva o de inspección.

## Crear un plan preventivo

<Steps>
  <Step title="Ir a Gestión de Mantenimiento > Planes Preventivos">
    Hacé clic en **Nuevo plan**.
  </Step>
  <Step title="Datos generales">
    Completá nombre, código, descripción y prioridad del plan.
  </Step>
  <Step title="Seleccionar activo">
    Asigná el activo que recibirá el mantenimiento. El plan queda vinculado a ese activo.
  </Step>
  <Step title="Configurar el disparador">
    Elegí el tipo (calendario, uso o condición) y completá los parámetros correspondientes.
  </Step>
  <Step title="Agregar tareas">
    Definí el checklist de trabajo. Podés importar desde un [Grupo de Tareas](/pulse/task-groups) o escribirlas manualmente.
  </Step>
  <Step title="Asignar responsables">
    Asigná los técnicos o equipos que ejecutarán las órdenes generadas.
  </Step>
  <Step title="Activar el plan">
    Toggleá el plan a **Activo**. A partir de ese momento, Pulse monitorea el disparador y genera órdenes automáticamente.
  </Step>
</Steps>

## Campos del plan

| Campo | Descripción |
|---|---|
| **Nombre** | Nombre descriptivo del plan |
| **Código** | Identificador único (ej. PM-001) |
| **Descripción** | Detalles del mantenimiento a realizar |
| **Prioridad** | Prioridad de las órdenes generadas |
| **Activo** | Equipo que recibe el mantenimiento |
| **Fecha inicio/fin** | Vigencia del plan |
| **Tolerancia de atraso** | Días de gracia antes de considerar una orden como atrasada |
| **Tipo de disparador** | Calendario, uso o condición |
| **Asignados** | Técnicos o equipos responsables |
| **Tareas** | Checklist de trabajo a incluir en cada orden generada |
| **Sub-órdenes** | Órdenes hijas que se generan junto con la principal |
| **Activo/Inactivo** | Si el plan está generando órdenes o pausado |

## Vista Gantt

La vista Gantt muestra todos los planes activos en una línea de tiempo, con las órdenes generadas y las próximas proyectadas. Es útil para visualizar la carga de mantenimiento preventivo en el tiempo y detectar solapamientos.

## Importar planes

Podés importar múltiples planes preventivos desde un archivo XLSX usando la opción **Importar** en la lista de planes. Descargá la plantilla, completala y subila.

## Órdenes generadas

Desde la pestaña **Órdenes** dentro de un plan podés ver todas las órdenes que generó ese plan, con su estado actual. Si una orden está atrasada (no se completó dentro del período esperado), aparece marcada.

<Tip>
  Configurá la **tolerancia de atraso** según la criticidad del equipo. Un compresor crítico puede tener 0 días de tolerancia; un equipo auxiliar puede tener 7 días.
</Tip>

<Tip>
  Para planes por uso, asegurate de que los técnicos registren lecturas de parámetros regularmente. Sin lecturas actualizadas, el sistema no puede detectar cuándo disparar la orden.
</Tip>

<Note>
  Un plan inactivo no genera nuevas órdenes, pero las órdenes ya generadas siguen su ciclo de vida normalmente.
</Note>
